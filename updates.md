# Darshan Gohel Portfolio Redesign Brief

## Vision

Create a portfolio that feels like a calm evening in an Indian city under a vast sky filled with bright white clouds.

The design should blend:

* Modern Developer Portfolio
* Pixel Art Aesthetics
* Minimalism
* Atmospheric Sky-Inspired Colors
* Subtle Nostalgia

The website should feel personal, creative, and human rather than looking like another generic SaaS landing page.

The goal is to communicate:

> "A developer building meaningful products from simple beginnings."

---

# Core Design Philosophy

## What We Want

* Calm
* Airy
* Spacious
* Creative
* Memorable
* Personal
* Premium
* Modern

## What We DON'T Want

* Generic AI startup design
* Excessive gradients
* Neon cyberpunk aesthetic
* Purple-blue SaaS themes
* Overly dark hacker-style portfolio
* Excessive glassmorphism
* Cluttered layouts
* Too many colors

---

# Pixel Theme Guidelines

The website should NOT be fully pixel art.

Use:

* Pixel icons
* Pixel borders
* Pixel cursor
* Pixel buttons
* Pixel hover effects
* Pixel loading animations

Avoid:

* Fully pixelated text
* Pixelated layouts
* Retro game interfaces
* Heavy arcade aesthetics

Target ratio:

70% Modern Design
30% Pixel Inspiration

---

# Typography

Primary Font:

* Geist
* Inter
* General Sans

Headings:

* Bold
* Large
* Clean

Body Text:

* Highly readable
* Spacious line-height

Avoid:

* Retro pixel fonts for paragraphs
* Fancy decorative fonts

Pixel fonts should only be used for:

* Small labels
* Badges
* Section indicators
